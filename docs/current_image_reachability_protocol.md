## Fixed-label question

For every finding, enumerate FOUR symbolic report label states: positive,
negative, uncertain and unknown. These are NOT generated report candidates,
not decoded text, and not a combinatorial report search.

With fixed EHR state `e` and image classifier state `x`, a report state `r`
supports all three iff `e`, `x`, `r` are explicit and equal. Therefore:

```text
maximum triple support with report changes only
  = number of known EHR facts with explicit agreeing fixed image labels
```

The denominator is ALL known direct EHR facts, never only comparable facts.
With no known EHR facts the ratio is unavailable, not zero or perfect.
For an explicit fixed EHR–image opposition, each explicit report state opposes
at least one report edge; unknown/uncertain only silence comparisons. The fixed
EHR–image opposition remains regardless of report. This is a label-domain
upper bound; it is not an achievable decoded report, a bound on every
quality-gated transition, clinical accuracy, or proof the image is wrong.
Do not prevent report structure/factuality improvements from this bound alone.
